# Sravya Varada | AI Engineer Portfolio

An interactive, high-end portfolio website showcasing expertise in AI Engineering, RAG systems, and Reinforcement Learning.

## 🚀 Features

- **Interactive Hero Section**: Mouse-reactive gradients and animated typing roles.
- **AI Pipeline Visualizations**: Interactive RAG architecture diagram built with React Flow.
- **RL Simulation**: Visual representation of multi-worker reinforcement learning tracking.
- **AI Chat Assistant**: A frontend-only chatbot trained on resume data.
- **Developer Terminal**: An interactive terminal for technical exploration.
- **Skill Universe**: Interactive visualization of the technical stack.
- **Smooth UX**: Momentum scrolling with Lenis and fluid animations with Framer Motion.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Visualizations**: React Flow, Recharts
- **Icons**: Lucide React
- **Smooth Scroll**: Lenis

## 📦 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
